# 🚀 Landing Page Responsiva

Landing page desenvolvida com foco em **design moderno, responsividade e experiência do usuário**, utilizando HTML, CSS e JavaScript.

O projeto foi criado para praticar e demonstrar conceitos de desenvolvimento Front-End, incluindo animações, interações e adaptação para diferentes tamanhos de tela.

## 🌐 Sobre o projeto

A proposta deste projeto foi desenvolver uma landing page visualmente atrativa e objetiva, apresentando conteúdos e produtos de maneira organizada.

O layout foi desenvolvido com atenção à hierarquia das informações, navegação simples e elementos interativos para tornar a experiência do usuário mais dinâmica.

## 🖥️ Preview

A página conta com uma interface moderna e elementos visuais que ajudam a destacar as principais informações.

Entre os elementos presentes estão:

- Área principal de destaque
- Apresentação de produtos ou serviços
- Imagens em destaque
- Navegação entre conteúdos
- Botões de chamada para ação
- Indicadores visuais
- Animações e transições

## 🎯 Botão "Saiba Mais"

Um dos elementos de destaque do projeto é o botão **Saiba Mais**, desenvolvido com animações para deixar a interação mais moderna.

O botão possui:

- ✨ Efeito de brilho
- 🎨 Gradiente animado
- ➜ Animação da seta
- 🌟 Efeito de destaque ao passar o mouse
- 📱 Adaptação para dispositivos móveis

## 🎨 Interface

O design foi desenvolvido buscando uma aparência moderna e limpa.

Durante o desenvolvimento foram trabalhados:

- 🎨 Organização visual dos elementos
- 🖼️ Tratamento e apresentação de imagens
- ⚡ Animações em CSS
- 🖱️ Interações com hover

- 🧭 Navegação intuitiva

## 🧩 Desenvolvimento

O projeto foi desenvolvido utilizando **HTML, CSS e JavaScript**, sem utilização de frameworks.

Durante o desenvolvimento foram aplicados conceitos como:

- Estruturação semântica com HTML
- Flexbox e Grid Layout
- Media Queries
- Manipulação do DOM com JavaScript
- Eventos e interações
- Transições CSS
- Keyframes e animações
- Organização e reutilização de estilos

## 📱 Responsividade

A landing page foi adaptada para funcionar em diferentes tamanhos de tela:

- Desktop
- Notebook
- Tablet
- Smartphone

Os elementos se reorganizam de acordo com o tamanho da tela para manter uma boa experiência de navegação.
